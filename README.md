# Once Human Build Simulator

Single-file HTML/JS/CSS Once Human build simulator.

## Features
- 6 armor slots with per-piece tier, stars, mods, accessories, and hides
- Weapon configuration
- Combat deviations (equip by clicking)
- Armor set bonuses (1-4pc)
- Aggregated stats and DPS comparison (with/without deviation)
- Rarity-colored UI matching the game

## Live Demo
Once the full `index.html` is on the `main` branch and GitHub Pages is enabled:

**https://ivan-j-rodriguez.github.io/once-human-build-sim/**

### Enable GitHub Pages
1. Go to the repository Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / `/ (root)`
4. Save

The full simulator is in the local artifacts. Click a deviation or set to equip it and switch to the Results tab.
